This project is a Multi-API Student AI Assistant built using Python. It is a command-line based assistant that interacts with multiple public APIs to provide real-time information to users. The assistant can fetch the latest news, display COVID-19 statistics for any country, provide dictionary meanings of words, and even tell random jokes. The project demonstrates how to integrate external APIs using Python and handle JSON responses effectively.

The program uses the requests library to send HTTP requests to different APIs and retrieve data in JSON format. Based on the user’s input, the assistant identifies the requested service (news, COVID stats, dictionary meaning, or joke) and calls the appropriate function. Each function processes the API response and displays formatted output in the console. The program runs in a continuous loop until the user types exit, making it interactive and user-friendly.

This project showcases practical concepts such as API integration, JSON parsing, conditional statements, loops, and modular function design in Python.
